Kết nối Facebook Page

Dán User Token có sẵn

Dán User Token từ tài khoản Facebook có quyền tạo nội dung trên Page và quản lý quảng cáo. Công cụ tự xác minh loại token, tải Page và chọn tài khoản quảng cáo đang hoạt động. Page Token và System User Token sẽ được báo rõ để thay bằng User Token.

Nâng cao
